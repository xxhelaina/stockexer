# StockLab A股复盘训练

桌面端 K 线复盘与交易训练工具，支持在线免费行情、本地行情导入、多周期切换、
双盲模式和模拟买卖。

界面采用类似成熟行情训练软件的两阶段工作流：未开始时只显示居中的“新建训练”
工作区，集中完成数据、起点、资金和规则配置；开始后切换到专注的图表工作区，
左侧是全高图表，右侧集中显示下一根、买入、卖出、数量、仓位、持仓概览、
权益与成交记录。参考 ChartMini 的布局与操作流程，但不是相同的图表引擎。

## 训练功能

- 鼠标移动十字光标，显示价格和时间；滚轮缩放，Ctrl＋滚轮以鼠标位置为缩放锚点，按住左键拖动平移。
- MA、成交量、MACD 可独立开关；支持水平线、两点趋势线和图表截图。
- 趋势线支持实时预览；切回“十字光标”后，点击线条选中，拖动整条线或端点。
  空白处拖动仍然平移图表；画线保持时间、价格锚点，不随缩放漂移。
- 可删除选中画线、撤销/重做、设置颜色/粗细/线型、锁定以及统一隐藏。
  清空作用于所有周期，但可以撤销；画线仅在创建时的周期显示。
  画线样式和锁定状态随训练保存，撤销记录仅保留当前会话最近 100 次操作。
- 自动回放支持 0.5 / 1 / 2 秒步进，可随时暂停。
- 本地分钟数据按原始周期开始训练；选择首根时自动留出历史窗口。
- 切换周期保留账户和实际回放时间；当前粗周期蜡烛只聚合已经揭示的行情。
- 买卖成交点标在图表上；模拟成交价需在当前 K 线高低价范围内。
- 默认 T+1，勾选“允许 T+0”后可当日卖出。采用简化的买入 100 股整数倍规则，
  卖出可包含零股；不是各板块交易规则的完整复刻，不支持卖空、挂单或撮合。
- “结束本轮”显示按当前市价估值的结算，不自动平仓；“新一轮训练”保留行情。
- “保存训练 / 恢复训练”使用 JSON 存档，包含行情、持仓、成交、画线和图表设置。
  将存档复制到另一台已安装 Python 和项目依赖的电脑，可离线继续。

## 启动

```powershell
python -m pip install -r requirements.txt
python main.py
```

Windows 也可以直接双击 `start_stocklab.bat`。启动脚本会自动切换到项目目录；
如果缺少依赖或启动失败，命令窗口会保留错误信息，不会直接闪退。

## 数据来源

- 在线行情按 `BaoStock → 东方财富 → 新浪 → 腾讯` 自动切换。
- BaoStock 支持 5/15/30/60 分钟及日/周/月线，适合获取较长历史区间。
- 1 分钟行情使用东方财富，并在失败时切换新浪/腾讯；免费源的历史范围有限。
- 在线数据会缓存到 `下载数据/股票代码_周期.csv`，断网时可从“导入本地”重新载入。

## 本地文件

“导入本地”会自动识别周期和格式，不再需要手动选择 1 分钟或日线。支持：

- `.csv`、`.tsv`、通达信 `.txt` 和二进制 `.day`；
- UTF-8、UTF-8 BOM、GBK/GB18030；
- 逗号、制表符、分号或空白分隔；
- `datetime/open/high/low/close/volume` 等英文表头；
- `日期/时间/开盘/最高/最低/收盘/成交量` 等中文表头；
- BaoStock 的 17 位 `time` 时间戳。

导入时会检查空数据、重复时间、非数值价格以及 OHLC 关系，错误信息会指出缺失列。

> 本软件只用于行情复盘训练，不构成投资建议。免费数据源可能延迟、限流或调整接口，
> 关键用途请使用有授权的数据服务。

## 快捷键

- `F8`：买入
- `F9`：卖出
- `F10`：下一根 K 线
- `F5`：K线/分时切换
- `← / →`：始终逐根平移图表，不移动光标（与光标模式无关）
- `↑ / ↓`：放大 / 缩小图表
- `Ctrl＋滚轮`：以鼠标处为锚点缩放（不会揭示未来 K 线）
- `Esc`：取消未完成画线/拖动，退出光标并返回查看模式
- `Delete / Backspace`：删除选中且未锁定的画线
- `Ctrl+Z`：撤销画线操作
- `Ctrl+Y / Ctrl+Shift+Z`：重做画线操作
