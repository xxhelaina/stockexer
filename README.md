# StockLab A股复盘训练

桌面端 K 线复盘与交易训练工具，支持在线免费行情、本地行情导入、多周期切换、
双盲模式和模拟买卖。

界面采用类似成熟行情训练软件的两阶段工作流：未开始时只显示居中的“新建训练”
工作区，集中完成数据、起点、资金和规则配置；开始后切换到专注的图表工作区，
训练页采用传统行情终端结构：左侧大面积黑底 K线 / 成交量 / MACD 三联图，
红色空心阳线、青色实心阴线，右侧窄幅行情与交易面板；账户/持仓和成交记录
通过标签页切换。顶部提供周期、指标、画线、平移缩放和截图工具，
“画线设置”展开颜色、线型、锁定及撤销等编辑操作。参考截图的布局，不复刻其图表引擎。
各图顶部显示指标参数及数值：MA1～MA6对应5/10/20/60/120/250根均线，
VOL/VOLUME是数据源原始成交量，MAVOL1/2对应5/10根量均线；MACD使用12/26/9。
数值跟随十字光标，↑/↓/→表示相对前一根的变化；无前一根时不显示箭头，
无有效值显示“--”。关闭光标后显示当前回放位置；历史不足周期时均线使用已有历史。

## 训练功能

- 开始前选择随机股票或指定6位代码，并设置开始/结束时间和训练周期。
  修改设置不会检索或下载；点击“开始训练”后才在后台检索本地行情。
- 优先检查当前导入数据、项目目录/下载缓存以及曾导入或扫描的目录；
  指定代码不会被上次导入的股票覆盖。随机模式优先从本地有效股票池抽取，
  本地不足时提示“本地导入 / 网上获取 / 取消”。选择本地导入会打开文件夹选择器，
  保留原股票、时间和周期并重新检索；只有选择网上获取才下载。
  随机模式选择网上获取后获取在线 A 股列表，最多尝试3只候选股票。
  在线股票池优先查询 BaoStock 历史列表，失败时使用东方财富当前列表；
  当前列表不能复原已退市股票，上市晚于训练区间的候选会因范围不足被跳过。
- 仅当数据可覆盖所选区间且周期可用时才开始；下载失败不会开始训练。
  支持从较细本地周期合成较粗周期，不会把5分钟线伪造为1分钟线。
  起点前历史保留给指标，结束时间之后的行情不进入本轮训练。
- 本地目录记录随软件设置保存；自动检索不遍历整台电脑，目录外的数据请先导入或扫描。
  可取消数据准备；正在进行的网络请求会在返回/超时后退出，旧结果不会覆盖新选择。
- 鼠标移动十字光标，显示价格和时间；滚轮缩放，Ctrl＋滚轮以鼠标位置为缩放锚点，按住左键拖动平移。
- MA、成交量、MACD 可独立开关；支持水平线、两点趋势线和图表截图。
- 趋势线支持实时预览；切回“十字光标”后，点击线条选中，拖动整条线或端点。
  空白处拖动仍然平移图表；画线保持时间、价格锚点，不随缩放漂移。
- 可删除选中画线、撤销/重做、设置颜色/粗细/线型、锁定以及统一隐藏。
  清空作用于所有周期，但可以撤销；画线仅在创建时的周期显示。
  画线样式和锁定状态随训练保存，撤销记录仅保留当前会话最近 100 次操作。
- 自动回放支持 0.5 / 1 / 2 秒步进，可随时暂停。
- 本地分钟数据按原始周期开始训练；选择首根时自动留出历史窗口。
- 切换周期保留账户和实际回放时间；当前粗周期蜡烛只聚合已经揭示的行情。
- 买卖成交点标在图表上；模拟成交价需在当前 K 线高低价范围内。
- 默认 T+1，勾选“允许 T+0”后可当日卖出。采用简化的买入 100 股整数倍规则，
  卖出可包含零股；不是各板块交易规则的完整复刻，不支持卖空、挂单或撮合。
- “结束本轮”显示按当前市价估值的结算，不自动平仓；“新一轮训练”保留行情。
- “保存训练 / 恢复训练”使用 JSON 存档，包含行情、持仓、成交、画线和图表设置。
  将存档复制到另一台已安装 Python 和项目依赖的电脑，可离线继续。

## 启动

Windows x64 用户可在 [GitHub Releases](https://github.com/xxhelaina/stockexer/releases)
下载免安装文件夹版，完整解压后双击 `StockLab.exe`；必须保留 `_internal` 文件夹。
详情见 [免安装版说明](docs/PORTABLE.md)。项目按 GPLv3 开源，见 `LICENSE`。

```powershell
python -m pip install -r requirements.txt
python main.py
```

构建 Windows 免安装版（Python 3.12 x64）：

```powershell
python -m venv .venv-release
.venv-release/Scripts/python.exe -m pip install -r requirements-release.txt
powershell -ExecutionPolicy Bypass -File scripts/build_release.ps1
```

Windows 也可以直接双击 `start_stocklab.bat`。启动脚本会自动切换到项目目录；
如果缺少依赖或启动失败，命令窗口会保留错误信息，不会直接闪退。

## 数据来源

- 在线行情按 `BaoStock → 东方财富 → 新浪 → 腾讯` 自动切换。
- BaoStock 支持 5/15/30/60 分钟及日/周/月线，适合获取较长历史区间。
- 1 分钟行情使用东方财富，并在失败时切换新浪/腾讯；免费源的历史范围有限。
- 在线数据按股票、周期、日期区间、复权选项和数据源分别缓存到 `下载数据/`，
  不覆盖原先的长区间缓存；旧的 `股票代码_周期.csv` 仍会被自动检索。
  同一区间重复下载也会另存版本，不盲目拼接不同来源或复权口径的数据。
- 自动准备会检查返回范围，不足时尝试下一源；无法覆盖时显示实际区间，
  不默默换成近期行情。BaoStock 查询在独立进程内执行，35秒未返回会超时切换。
- 范围检查会处理周末和午休，但不是逐根完整性认证，也未接入完整交易日历。
  若区间边界是节假日或停牌日，请按实际可用交易时间调整。

## 本地文件

“本地导入（文件夹）”选择数据目录；“单文件导入”可单独载入一个行情文件。
缺少数据提示中的“本地导入”也选择文件夹，不改变原来的训练参数。
自动识别周期和格式，不再需要手动选择 1 分钟或日线。支持：

- `.csv`、`.tsv`、通达信 `.txt` 和二进制 `.day`；
- UTF-8、UTF-8 BOM、GBK/GB18030；
- 逗号、制表符、分号或空白分隔；
- `datetime/open/high/low/close/volume` 等英文表头；
- `日期/时间/开盘/最高/最低/收盘/成交量` 等中文表头；
- BaoStock 的 17 位 `time` 时间戳。

导入时会检查空数据、重复时间、非数值价格以及 OHLC 关系，错误信息会指出缺失列。

> 本软件只用于行情复盘训练，不构成投资建议。免费数据源可能延迟、限流或调整接口，
> 关键用途请使用有授权的数据服务。

## 快捷键

- `F8`：买入
- `F9`：卖出
- `F10`：下一根 K 线
- `F5`：K线/分时切换
- `← / →`：始终逐根平移图表，不移动光标（与光标模式无关）
- `↑ / ↓`：放大 / 缩小图表
- `Ctrl＋滚轮`：以鼠标处为锚点缩放（不会揭示未来 K 线）
- `Esc`：取消未完成画线/拖动，退出光标并返回查看模式
- `Delete / Backspace`：删除选中且未锁定的画线
- `Ctrl+Z`：撤销画线操作
- `Ctrl+Y / Ctrl+Shift+Z`：重做画线操作
