# StockLab v0.1.0 — Windows x64 免安装版

首次提供无需安装 Python 的 Windows 文件夹版。
下载 `StockLab-v0.1.0-windows-x64.zip`，完整解压后双击 `StockLab.exe`。
不要单独移动 EXE，必须保留 `_internal`。

## 本版内容

- 传统行情终端布局：黑底 K线、成交量、MACD 三联图及窄幅交易侧栏。
- MA5/10/20/60/120/250、量均线和 MACD 数据跟随十字光标，附变化方向箭头。
- Ctrl＋滚轮在鼠标处缩放，左右键平移；画线预览、编辑、撤销、锁定和保存。
- 点击开始训练后检索本地和下载缓存；只有选择网上获取才下载。
- 修复打包后的 BaoStock 子进程启动及无控制台输出兼容问题。
- 缓存和日志保存到可写目录，不写入 `_internal`。
- 附 GPLv3 许可证、第三方授权说明、源码附件和 SHA256 校验文件。

## 使用限制

发布前验证：71 项回归测试通过；解压后的 EXE 在含中文和空格的目录中，
移除 PATH 中的 Python 后完成本地5分钟回放、子进程启动、BaoStock 下载及缓存读取。

- 面向 Windows 10/11 x64；本机测试不等同于所有电脑兼容性验证。
- 免费在线源的网络、限流及历史范围限制仍然存在，打包不会消除这些限制。
- 未代码签名，可能触发未知发布者提示。请核对下载来源和校验值。
- 仅用于复盘训练，不构成投资建议；交易规则是简化模拟。
